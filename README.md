# 儿童智力测试小程序 - 部署指南

## 项目概述
基于MBTI测试模式的儿童智力评估微信小程序，零成本方案，全程使用微信云开发免费额度。

- **前端**：微信小程序原生开发（WXML + WXSS + JS）
- **后端**：微信云开发（CloudBase）云函数 + 云数据库 + 云存储
- **图表**：Canvas 2D 原生绘制（雷达图 + 折线图）
- **题库**：225道题（5维度 × 3年龄段 × 3难度 × 5题）

---

## 一、环境准备

### 1. 注册微信小程序账号
1. 登录 [微信公众平台](https://mp.weixin.qq.com)
2. 使用企业/个体工商户资质注册小程序
3. 获取 **AppID**

### 2. 安装微信开发者工具
1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 安装并登录

### 3. 开通云开发
1. 在开发者工具中打开项目
2. 点击工具栏「云开发」按钮
3. 创建云开发环境（选择"按量付费"模式，免费额度内不产生费用）
4. 记录 **环境ID**

---

## 二、项目配置

### 1. 填入 AppID
打开 `project.config.json`，将 `appid` 替换为你的 AppID：
```json
"appid": "your-appid-here"
```

### 2. 填入云开发环境ID
打开 `miniprogram/app.js`，将 `cloudEnv` 替换为你的环境ID：
```js
globalData: {
  cloudEnv: 'your-cloud-env-id',
}
```

### 3. 创建云数据库集合
在云开发控制台 → 数据库中创建以下集合：
| 集合名 | 用途 | 权限设置 |
|--------|------|----------|
| `questions` | 题库 | 所有用户可读 |
| `children` | 儿童档案 | 仅创建者可读写 |
| `test_sessions` | 测试会话 | 仅创建者可读写 |
| `reports` | 测试报告 | 仅创建者可读写 |

---

## 三、部署云函数

在微信开发者工具中，右键每个云函数文件夹，选择「上传并部署」：

1. `cloudfunctions/initQuestions` - 题库初始化
2. `cloudfunctions/manageProfile` - 档案管理
3. `cloudfunctions/startTest` - 开始测试
4. `cloudfunctions/submitAnswer` - 提交答案
5. `cloudfunctions/finishTest` - 完成测试
6. `cloudfunctions/getReport` - 获取报告
7. `cloudfunctions/getHistory` - 历史报告

> ⚠️ 注意：`shared/testEngine.js` 是共享模块，部署各云函数时会自动包含。

---

## 四、初始化题库

1. 在开发者工具的云开发控制台中，找到云函数列表
2. 手动调用 `initQuestions` 云函数（或在调试器中执行）
3. 确认返回 `题库导入成功，共 225 道题`

---

## 五、本地调试

1. 在开发者工具中编译运行
2. 首页 → 创建儿童档案 → 开始测试
3. 完整走通：创建档案 → 答题30题 → 查看报告 → 历史记录 → 趋势图

## 七、核心功能说明

### 测试引擎
- 固定30题（5维度 × 6题/维度）
- 维度轮转：逻辑 → 语言 → 空间 → 记忆 → 创造 → 循环
- 难度自适应：答对率 ≥80% 难度+1，≤40% 难度-1
- 评分：每题满分10分，每维度满分60分，归一化至0-100

### 智力类型（8种）
| 类型 | 条件 |
|------|------|
| 全能小天才 | 五维度均≥60 |
| 未来工程师 | 逻辑+空间双高 |
| 文艺小少年 | 语言+创造双高 |
| 小小逻辑家 | 逻辑最高 |
| 空间探索者 | 空间最高 |
| 小小演说家 | 语言最高 |
| 记忆小达人 | 记忆最高 |
| 创意小画家 | 创造最高 |

### 断点续测
测试中途退出后，下次进入会检测未完成会话并提示继续。

## 八、上线发布

1. 在开发者工具中点击「上传」
2. 填写版本号（如 v1.0.0）和备注
3. 登录微信公众平台 → 版本管理 → 提交审核
4. 审核通过后点击「发布」

### 审核前自查清单
- [ ] 无空白页面
- [ ] 无测试数据残留
- [ ] 用户协议 + 隐私政策页面
- [ ] 无敏感权限滥用
- [ ] 内容合规
- [ ] 无外链跳转
- [ ] 所有按钮点击有效
- [ ] 类目选择正确（教育 > 婴幼儿/儿童教育）
